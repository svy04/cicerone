# 시장 근거

`modes/` 아래의 지시문이 한국 취업 시장에 대해 주장하는 것들의 출처입니다. 확인 시점은 2026년 8월 21일입니다.

이 문서를 두는 이유는 두 가지입니다. 첫째, 도구가 후보자에게 하는 말에 근거가 있어야 합니다. 둘째, 시장은 바뀌므로 어느 시점의 무엇을 근거로 삼았는지 남겨야 나중에 갱신할 수 있습니다.

**라벨**: 확인(1차 출처) · 관찰(표본이 밝혀진 조사나 실물 사례) · 추정(실무 증언만 있음) · 불명(근거를 찾지 못함)

## 갱신

시장 사실은 바뀝니다. 아래는 특히 빨리 낡습니다.

- 사회보험 요율과 국민연금 상한 (해마다 바뀝니다)
- 소득세 구간
- 공채 일정과 인적성검사 구성
- 채용 플랫폼의 이용약관과 API 정책
- 포괄임금제 규제 (2026년 기준 국회에 개정안이 계류 중입니다)

고칠 때는 이 문서와 `modes/` 아래 지시문을 함께 고칩니다. 한쪽만 고치면 서로 어긋납니다.
