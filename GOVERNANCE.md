# Governance

cicerone has a single maintainer: [@svy04](https://github.com/svy04). There is no
contributor ladder and no review committee — pretending otherwise would describe a
team that does not exist.

## How decisions get made

The maintainer decides. Disagreement belongs in a
[Discussion](https://github.com/svy04/cicerone/discussions) before a pull request,
so nobody writes code against a direction that will not be merged.

## What gets merged

A change is merged when the full check suite passes and the maintainer has read it.
`node test-all.mjs` is the bar; see [CONTRIBUTING.md](CONTRIBUTING.md) for what a
pull request needs to carry.

## Code of conduct

[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) applies to every space this project uses.
Report privately from this repository's **Security** tab.

## Upstream

This is a fork of [santifer/career-ops](https://github.com/santifer/career-ops),
which has its own governance. Nothing here binds that project, and nothing there
binds this one.
